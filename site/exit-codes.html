Installer Exit Codes

Last updated 19 September 2026

Summary

0 means the installer ran to completion. The Cleanup Assist installer is built with NSIS and does not define custom return codes, so it reports the standard NSIS set below and nothing more granular.

Codes the installer returns

CodeMeaningApplies to silent install
0 Installation completed successfully. Yes — verified for a first install, a repeat install over an existing one, and installation to an alternative directory.
1 The user cancelled the installation. This is the NSIS default for a user-initiated abort. No — a silent install (/S) presents no interface, so there is nothing for a user to cancel.
2 The installation was aborted by the install script. Rare — the installer does not deliberately abort under any supported condition.

Scenarios with no distinct code

The following conditions do not produce their own return value. The installer reports 0, and the outcome must be determined by checking whether the application is present afterwards.

  • Application already installed — reinstalling over an existing copy succeeds and returns 0.
  • Destination unreachable — for example a drive letter that does not exist. The installer returns 0 without installing.
  • Insufficient permissions for the target directory — the installer returns 0 without installing.
  • Disk full, network failure, installation already in progress, and blocked by device security policy — no dedicated code is emitted.
  • Reboot required — not applicable. Cleanup Assist never requires a restart to complete installation.

Verifying an installation succeeded

Because a 0 return value alone does not prove the files were written, confirm the installation by checking that the registry entry exists:

  • Key: HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\Cleanup Assist
  • The InstallLocation value gives the directory, and DisplayVersion the installed version.

The installer is per-user and requires no elevation. Silent installation uses the uppercase switch /S; a lowercase /s is ignored and the interface is shown instead.

Uninstalling

uninstall.exe /S in the install directory removes the application and its registry entry, returning 0.
